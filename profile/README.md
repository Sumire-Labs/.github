# Sumire Labs

This organization was born out of a desire to freely create whatever we felt like making on our Discord server; we named it "Sumire-Lab" by arbitrarily using the name of a friend—Sumire—who, despite having absolutely no background in development, frequently played games with us on the server.

[Discord](https://discord.gg/tJhM4HBHP2)
